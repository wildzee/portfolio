UI/UX audit — top issues

12 specific, fixable issues found. Click any you want fixed. Critical first.

🔴 critical
criticalContact section

1 · "Let talk" — missing apostrophe-s

The big contact heading is missing a word. First thing recruiters and clients see at the bottom of your page. Undermines credibility immediately.

→ Fix: "Let's talk" or "Let's work together"
🟠 high impact
highNavigation

2 · "Book a Call" hidden on mobile

Primary CTA is hidden sm:flex — disappears on phones. Most portfolio views happen on mobile. You're losing your main conversion point.

→ Move to sticky bottom bar or hamburger menu on mobile
highWorks section

3 · Work row arrow hidden on mobile

work-arrow is display:none on mobile. Users can't tell the rows are clickable. No affordance = no taps.

→ Add chevron icon visible on mobile
highTypography

4 · No consistent type scale

Hero: text-7xl. Rasoi Pay: text-[5.5rem]. About: text-[9rem]. Case studies feel like different sites. No shared h1/h2/h3 tokens.

→ Define 5-stop type scale in globals.css, use it everywhere
highSpacing / Rhythm

5 · Section padding varies wildly

Hero: pt-24 pb-16. Works: pt-16 pb-24. About: pt-20 pb-32. No vertical rhythm. Page feels uneven when scrolling fast.

→ Use 2–3 section spacing tokens consistently
highCase Studies

6 · Process steps inconsistent across pages

Rasoi Pay and Iqra use different expand/collapse patterns. Same portfolio, different component. Feels unfinished to anyone who reads both.

→ Consolidate into one reusable ProcessStep component
🟡 medium impact
mediumAccessibility

7 · No visible focus states on form inputs

Form inputs have focus:border-primary but no focus ring. Keyboard users get no feedback. WCAG AA fail.

→ Add focus:ring-2 focus:ring-primary/40 to all inputs
mediumContact section

8 · Contact CTA hierarchy unclear

The heading, email, and button fight for attention. No clear visual flow. Users don't know where to look first.

→ Big headline → email address → single primary button, spaced generously
mediumCase Study Footer

9 · Case study prev/next navigation unclear

Rasoi Pay footer: "Previous / Iqra" with no "next." Iqra footer is clearer. Visitors can't easily navigate between case studies.

→ Standardize with explicit Prev ← → Next labels, both sides
mediumVisual / Mobile

10 · Grain overlay hurts text legibility on mobile

Full-screen grain at fixed opacity covers all text on mobile screens. On small displays this reduces readability noticeably.

→ Reduce --grain-opacity at mobile breakpoint or limit to hero only
mediumAbout / Experience

11 · Experience expand icon no hover feedback

The + icon on experience rows has no pre-click hover state. Users aren't sure it's interactive until they click.

→ Add group-hover:text-primary and group-hover:scale-110 on icon
mediumTheme

12 · Dark mode has no CSS fallback

Theme toggle relies on JS class toggle. No prefers-color-scheme media query fallback. Users with JS disabled or slow load see wrong theme.

→ Add @media (prefers-color-scheme: dark) as baseline
